# Fidelity of the JAR version to the LIPIcs draft

`main.tex` here is generated by `port.py` from `../main.tex` (the LIPIcs draft) and builds
with the Springer Nature template. This file lists every difference between the two PDFs and
why it is there. The task was a format port: no sentence, theorem statement, listing, table,
figure or reference was to change.

Checked on 2026-11-01 with pdfTeX 1.40.25 (TeX Live 2023/Debian), `lipics-v2021.cls` v3.1.3
and the Springer Nature template package of December 2024 (the LIPIcs build used for the
comparison gave 17 pages on this machine; `../README.md` records 16 for the author's build), by

```bash
python3 fidelity.py <dir with the built LIPIcs main.tex/.bbl/.pdf> .
```

The script runs two checks.

1. **Source.** Every line of `../main.tex` from the Introduction to the end of the appendices
   must reappear, in order, in `main.tex`. Result: 785 of 790 lines copied unchanged. The five
   others are listed below under "Source changes"; none is a sentence of the paper.
2. **PDF text.** `pdftotext` of both PDFs, then a character-level diff after removing what the
   class alone changes: page numbers, the LIPIcs running heads, theorem end marks and bullets,
   whitespace and hyphens (line breaks, hyphenation and math spacing move with the narrower
   text block), and citation numbers (the two styles number the references differently; the
   cited keys are covered by check 1, since every `\cite` is in a copied line). The two
   reference lists are compared by BibTeX key. Result: the same 41 entries, and 33 text
   differences, all listed below.

## Source changes (check 1)

| LIPIcs `main.tex` | JAR `main.tex` | Reason |
|---|---|---|
| (none) | `\setlength{\tabcolsep}{5pt}` before the tabular of Table 2 | Layout. sn-jnl's text block is narrower, and Table 2's six columns (fractions of `\textwidth` plus column separation) overflowed by 1.3 pt. |
| comment on Dagstuhl's GenAI policy above "Use of generative AI" | comment on Springer Nature's AI policy | Comment only; nothing printed. |
| `\bibliography{../docs/paper-refs,extra}` before the appendices | `\backmatter`, Supplementary information, Declarations, then `\begin{appendices}` | Template structure: back matter, then appendices, then references (template user manual, section 5). The bibliography line moves after `\end{appendices}`, with paths one level deeper. |
| `\appendix` | `\begin{appendices}` … `\end{appendices}` | Template's appendix environment. |

Outside the body, the preamble and front matter are replaced (class, packages, theorem
environments, title, author, abstract, keywords); the `\lstdefinelanguage` and `\lstset` of
the listings are copied unchanged.

the same.

## Not checked by the script

* Hyphens inside words are ignored by check 2. Check 1 covers them for the body, since its
  lines are compared exactly.
* Visual inspection of every page was done once, on 2026-11-01 (21 pages), and found the
  appendix listings, tables and theorem headings in place.
